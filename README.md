# 项目简介

## 核心功能
- 基于YOLOv8的骑行者检测系统，支持图片、视频及摄像头进行实时检测
- 包含5000张标注数据集，涵盖['cyclist', 'person']两类目标
- 支持选择检测模型并自定义置信度、IOU阈值
- 界面实时显示目标位置、目标总数、置信度等信息
- 支持批量检测功能，可直接查看所有检测结果
- 提供检测结果保存功能
- 支持选择显示标签和原图

## 适用场景
- 骑行安全监控系统
- 交通流量分析
- 智能监控与安防系统
- 运动数据分析与研究
- 城市交通管理

## 技术特点
- 基于Pycharm+Anaconda或VSCode+Anaconda开发环境
- 使用Python3.9、opencv-python、PyQt5、ultralytics、torch1.9等技术栈
- 提供完整的UI界面源文件和图标资源
- 包含训练好的模型及训练结果
- 配置成功环境可直接使用，无需重新训练
